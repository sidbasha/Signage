# 5. API reference

> Endpoint tables are generated by `docs/_tools/gen_api_doc.py` from the controllers and `docs/api/openapi.json`; examples are real responses captured from a running instance (`docs/api/samples.json`). The interactive version is at **`/swagger`** (enabled in Development, or with `Swagger__Enabled=true`).

## 5.1 Conventions

| Topic | Rule |
|---|---|
| Base URL | Same origin as the UI, e.g. `https://signage.example.com`. All endpoints are under `/api`, hubs under `/hubs`. |
| Format | JSON, camelCase. Enums are strings (`"AndroidTv"`). Dates are ISO-8601 UTC; `DateOnly` is `"2026-09-21"`, `TimeOnly` is `"07:00:00"`. |
| IDs | UUIDs. Routes constrain them (`{id:guid}`), so malformed ids give 404. |
| Tenancy | Implicit: the caller's organization comes from the token. Another organization's ids return **404**, never 403. |
| Updates | `PUT` replaces the resource, including child collections (playlist items, layout zones, schedule targets, group members). |
| Pagination | Only `/api/audit-logs` is paged (`page`, `pageSize` → `{ items, total, page, pageSize }`). Other lists return all rows for the organization. |

## 5.2 Authentication, errors and limits

**Admin (JWT).** `POST /api/auth/login` returns a 15-minute access token and a 14-day refresh token. Send `Authorization: Bearer <accessToken>`. On 401, call `POST /api/auth/refresh` once, then retry. The SPA does this with single-flight refresh, because refresh tokens are single use.

```bash
TOKEN=$(curl -s -X POST localhost:5080/api/auth/login -H 'Content-Type: application/json' \
  -d '{"email":"admin@demo.local","password":"Admin@12345"}' | jq -r .accessToken)
curl -s localhost:5080/api/devices -H "Authorization: Bearer $TOKEN" | jq '.[].name'
```

JWT claims: `sub` (user id), `email`, `name`, `jti`, `org`, `org_name`, one `role` per role, and one `perm` per permission. Permission changes take effect when the token next refreshes (≤ 15 min).

**Device (key).** Players send `Authorization: Device <deviceKey>`. On `/hubs/device`, the key may also come as `Bearer` or `?access_token=`. The two schemes are exclusive: a JWT can't call the player API, and a device key can't call admin endpoints.

**Permissions** (23): `dashboard.view`, `organization.manage`, `users.view`, `users.manage`, `roles.manage`, `locations.view`, `locations.manage`, `devices.view`, `devices.manage`, `devices.pair`, `devices.command`, `groups.manage`, `media.view`, `media.manage`, `playlists.view`, `playlists.manage`, `layouts.view`, `layouts.manage`, `schedules.view`, `schedules.manage`, `audit.view`, `subscription.view`, `subscription.manage`.

| Built-in role | Permissions |
|---|---|
| Owner | all 23 |
| Admin | all except `subscription.manage` |
| Editor | every `*.view` except `audit.view`, plus `media.manage`, `playlists.manage`, `layouts.manage`, `schedules.manage`, `devices.command` |
| Viewer | every `*.view` except `audit.view` |

**Errors** use RFC 7807 `application/problem+json`, always with `traceId`. Validation errors add `errors: { field: [messages] }`:

```json
{
  "title": "Validation failed",
  "status": 400,
  "detail": "One or more fields are invalid.",
  "instance": "/api/locations",
  "errors": {
    "name": [
      "name is required."
    ],
    "timeZone": [
      "Choose a valid IANA time zone, for example Asia/Kolkata."
    ]
  },
  "traceId": "0HNOO14QK6A14:00000001"
}
```
```json
{
  "title": "Not found",
  "status": 404,
  "detail": "Device '00000000-0000-0000-0000-000000000001' was not found.",
  "instance": "/api/devices/00000000-0000-0000-0000-000000000001",
  "traceId": "0HNOO14QK6A15:00000001"
}
```

| Status | Meaning |
|---|---|
| 400 | Validation failed (`errors` holds per-field messages; zone errors use keys like `zones[0]`) |
| 401 | Missing, invalid or expired token or device key; wrong password |
| 402 | Plan limit reached (devices, users, storage) or a plan downgrade is blocked by usage |
| 403 | Signed in but missing the permission; read-only resource (template, built-in role); invalid file signature |
| 404 | Not found, or belongs to another organization |
| 409 | Conflict: duplicate email or name, resource still in use |
| 413 | Upload larger than 1 GB |
| 429 | Rate limited: `auth` policy 20 requests/min/IP (all `/api/auth/*`), `pairing` policy 60/min/IP |
| 500 | Unexpected; details only in Development. Search logs by `traceId`. |
